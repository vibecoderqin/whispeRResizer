# Twitch Whisper Resizer

Расширение для Chrome Manifest V3, которое позволяет менять размер **открытых** окон личных сообщений (whispers) на Twitch. Размер запоминается отдельно для каждого собеседника.

## Возможности

- Ручка изменения размера добавляется внутрь открытого окна переписки, а не в уведомления-превью.
- Для распознавания открытого окна проверяются одновременно заголовок, видимый элемент ввода сообщения и минимальный размер контейнера. DOM-селекторы собраны в начале content.js для быстрой адаптации к изменениям Twitch.
- Размеры хранятся отдельно по username собеседника в chrome.storage.local.
- Минимальные/максимальные ширина и высота, цвет и размер ручки настраиваются на странице расширения. Эти настройки хранятся в chrome.storage.sync.
- Сохранение размера происходит после окончания перетаскивания, а не при каждом движении указателя.
- Pointer Events поддерживают мышь, тач и стилус.
- При изменении размера браузера окно ограничивается видимой областью.
- Ctrl + Shift + стрелки меняют размер активного диалога на 10 px. Горячие клавиши не срабатывают в полях ввода.
- Кнопка в настройках сбрасывает сохранённые размеры.

## Установка для разработки

1. Склонируйте или скачайте репозиторий.
2. Откройте chrome://extensions.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку проекта.
5. Откройте Twitch на www.twitch.tv.

После изменения файлов нажмите «Обновить» на странице расширений и обновите вкладку Twitch.

## Настройки

Откройте подробности расширения в chrome://extensions и выберите «Параметры расширения». Минимальные значения по умолчанию сохранены: ширина 200 px, высота 150 px. Максимальный размер дополнительно ограничивается видимой областью браузера.

## Ручная проверка

1. Получите новое whisper-уведомление, но **не нажимайте** на него. Уведомление должно сохранить штатный размер; ручки на нём быть не должно.
2. Откройте полный диалог с собеседником. После появления заголовка и поля ввода должна появиться ручка. Потяните её мышью; после отпускания указателя размер должен сохраниться.
3. Откройте переписку с другим собеседником и задайте другой размер. Вернитесь к первому — у каждого диалога должен сохраниться собственный размер.
4. Проверьте перетаскивание пальцем на устройстве с тач-экраном или стилусом.
5. Щёлкните по окну, затем нажмите Ctrl + Shift + стрелку. Размер должен меняться шагом 10 px. Внутри поля ввода комбинация не перехватывается расширением.
6. Измените размер окна браузера: размеры открытых диалогов должны быть ограничены текущей видимой областью.
7. В параметрах измените цвет/размер ручки и пределы окна. Изменения должны примениться без переустановки расширения. Проверьте сброс размеров.
8. Закройте диалог или верните его в состояние уведомления-превью. Ручка и инлайновые стили расширения должны быть удалены.

## Совместимость и известные ограничения

Twitch регулярно меняет DOM, поэтому открытое состояние распознаётся эвристически по контейнеру диалога, заголовку, видимому composer/input и минимальным габаритам. Если Twitch переименует селекторы ввода/заголовка, обновите массивы DOM_SELECTORS в начале content.js. Если окно перестало распознаваться, откройте DevTools на полном диалоге и убедитесь, что селектор composer указывает на реально видимый элемент ввода; затем проверьте тот же селектор для компактного уведомления — он не должен совпадать.

Расширение запускается только на страницах *://www.twitch.tv/* и использует лишь permission storage.
