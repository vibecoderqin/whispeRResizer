# Twitch Whisper Resizer

Расширение Chrome на Manifest V3 для изменения размера открытых окон личных сообщений Twitch.

## Возможности

- Невидимая область захвата располагается слева сверху вне окна и не содержит иконок или графики. Курсор показывает возможность изменения размера; перетаскивание влево/вверх увеличивает окно, противоположный нижний правый угол остаётся на месте.
- Область захвата создаётся только для открытых окон переписки, когда обнаружены видимый заголовок и поле ввода сообщения. Уведомления-превью не должны изменяться.
- Размер сохраняется отдельно для каждого собеседника.
- Pointer Events поддерживают мышь, сенсорный экран и стилус; запись размера выполняется при завершении перетаскивания.
- Страница настроек позволяет менять пределы размера, размер невидимой области захвата и сбрасывать сохранённые размеры.
- Иконки расширения и кнопка на панели Chrome удалены. Настройки открываются через `chrome://extensions` → «Подробности» → «Параметры расширения».
- Временная диагностика записывает состояние DOM и причины, по которым элементы не распознаны. Экспорт создаёт JSON-файл; тексты сообщений не собираются.

## Установка и обновление

1. Откройте \`chrome://extensions\`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку проекта.
4. После обновления исходников нажмите кнопку обновления расширения на этой странице, затем перезагрузите вкладку Twitch.

## Настройки и диагностика

Откройте `chrome://extensions`, найдите Twitch Whisper Resizer и перейдите в «Подробности» → «Параметры расширения».

Если область захвата не появляется:

1. Откройте страницу параметров и включите «Сбор отладочных событий».
2. Перейдите на Twitch, перезагрузите страницу и откройте полноценный whisper-диалог с заголовком и полем ввода.
3. Вернитесь в параметры и нажмите «Экспортировать debug JSON».
4. Проверьте отчёт: в нём есть количество элементов-кандидатов, совпадения селекторов и причина отклонения (например, \`header-not-found\` или \`composer-not-found\`). Логи не содержат текста сообщений.
5. После диагностики отключите сбор и при необходимости нажмите «Удалить debug-логи».

DOM Twitch меняется со временем. Селекторы собраны в начале \`content.js\`; алгоритм предпочитает внешний элемент окна, чтобы случайно не выбрать вложенную обёртку без заголовка или composer.

## Разработка

- `manifest.json` — настройки MV3 и разрешения; манифест не объявляет иконки или action-кнопку.
- Фонового обработчика нет: открыть Options Page можно из раздела сведений о расширении.
- `content.js` / `content.css` — распознавание диалогов, область захвата и изменение размеров.
- \`options.html\` / \`options.js\` — настройки и экспорт отладки.

Файлы иконок удалены из проекта; расширение не объявляет собственные иконки.

Разрешение расширения ограничено \`storage\`; content script запускается только на \`*://www.twitch.tv/*\`.
